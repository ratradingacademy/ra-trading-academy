# RA Trading Academy Website

A responsive static website for GitHub Pages, using the RA dark navy, orange, and gold brand theme.

## Included
- Home, About, Courses, 15-Day Masterclass, Reviews, Contact, and Privacy Policy pages
- One complete 15-Day Trading Masterclass, progressing from basics to advanced concepts
- No separate Beginner or Advanced Mentorship offering; legacy URLs redirect to the masterclass
- No blog page or blog navigation
- RA logo and masterclass poster (poster is used selectively rather than repeated across sections)
- WhatsApp click-to-chat, click-to-call, email, Instagram, Google review link, and map embed
- Responsive styling, SEO metadata, EducationalOrganization schema, robots.txt, and sitemap.xml

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the **contents** of this folder into the root of `ratradingacademy/ra-trading-academy` (not the enclosing folder).
3. Ensure `index.html` is at the repository root.
4. Commit to the branch/folder configured in Settings → Pages.
5. Wait for the Pages deployment to finish, then open the published URL.
